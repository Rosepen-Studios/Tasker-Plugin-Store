# Tasker Plugin Store

A collection of plugins for the Tasker app. This repository is maintained by Rosepen Studios, the developers of Tasker, and is intended to provide a curated selection of plugins that are compatible with the app. It also serves as a central location for plugin developers to submit their plugins for inclusion in the store.

## Available Plugins

### Time Management
- **Focus**: A plugin for managing focus and productivity.

### Quality of Life
- **Habits**: Create new habits by tracking your progress and staying motivated.

## Submitting Your Plugin
If you are a plugin developer and would like to submit your plugin to the Tasker Plugin Store, please follow these steps:

1. Create a new issue in this repository using the "Plugin Submission" template.
2. Provide the following information in your submission:
	 - Plugin name
	 - Description of the plugin and its functionality
	 - Link to the plugin's source code repository (needs to be public on GitHub)
	 - A list of the version codes your plugin has available, along with the GitHub link for each of those releases (e.g., "1.0_0.1", "1.1_1.3"). If you don't know what these are, please see the [Plugin Publishing Guide](https://rosepen-studios.gitbook.io/tasker/guides/guides/11.-publishing)
	 - Your plugins ID (needs to follow the format "com.developername.pluginname", e.g., "com.rosepen.focus")
	 - Any additional information you think is relevant for your plugin submission.
3. Publsih your request and wait for a response from us. We will review your submission and get back to you.

Please not that for security and privacy reasons, we do not accept plugins that are not open-source or that are hosted on private repositories. We also review each submission's source code to ensure that it does not contain any malicious code or violate any privacy policies. If your plugin is accepted, it will be added to the Tasker Plugin Store and made available for users to download and install. Should your plugin be rejected, we will provide feedback on the reasons for rejection and any necessary changes that need to be made before resubmission. If malicious code is found in your plugin, we will remove it from the store/reject it and may take further action, including reporting the plugin to GitHub and/or other relevant authorities.

## Removing Your Plugin
You can at any point remove your plugin from the store by creating a new issue in this repository using the "Plugin Removal" template. Please provide the plugin's name and ID, and we will remove it from the store.
